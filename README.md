# Presently

A browser-based presentation editor with a live slide preview. Create a short deck, choose a theme, and present it directly from your browser.

**[Open the live demo](https://avi-808.github.io/presently-presentation-builder/)**

## Features

- Edit slide titles, subtitles, and key points.
- Add, navigate, and delete slides.
- Choose from four visual themes.
- Present full screen with keyboard navigation.
- Print or save slides as a PDF from the browser.
- Save drafts in local storage on this device.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.

## Current scope

This is a front-end project. Drafts remain in the current browser and are not shared or synchronized between people. It does not currently generate slides with AI or upload presentations to a server.
